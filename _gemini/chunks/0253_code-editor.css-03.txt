/* ── 强制颜色模式（EDIT-01 第 5 条：不能因为透明 textarea 让文字消失） ──────
   基座的做法是「输入层文字涂透明、由它下面那层高亮层负责看得见」。而强制颜色模式会把
   系统调色板直接套到 `color` 上——`transparent` 不再透明，同一个字符于是被画两遍并逐列
   错位成重影；反过来只保高亮层，输入层又可能整片看不见。
   这里不再玩叠层：文字只由真实 textarea 承担（CanvasText），高亮层整层隐掉。
   代价如实写清：强制颜色下**没有语法着色**——该模式下系统本就覆盖自定义色，
   留着叠层只会重影，不会多出信息量。 */
@media (forced-colors: active) {
  div.code-editor textarea { color: CanvasText; background: Canvas; }
  pre.code-tokens { visibility: hidden; }
  /* 当前行不靠颜色与遮光带表达：左侧一道系统色实线 + 行号加粗（字重本就是 700）。 */
  div.code-highlight { background: transparent; border-left: 2px solid CanvasText; }
  div.line-numbers span.active { color: CanvasText; }
  div.line-numbers { border-right-color: CanvasText; }
  div.code-editor { border-color: CanvasText; }
  div.code-footer { border-top-color: CanvasText; }
}

/* ── 自动换行（EDIT-01 第 2 条的设置项） ────────────────────────────────
   默认**不开**：§5.4 的「长代码行」取证形态量的就是不开时的横向滚动。
   开了要两层一起改，否则高亮层折行、输入层不折，逐行立刻错位。 */
