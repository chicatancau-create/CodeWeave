     照搬会把装饰框压在顶栏之上。geometry.md §5 末尾明确「层级常量的落地由共享层
     在 styles.css 内决定」，故这里定义产品档位；除下列五档外不得再新增数值。
       裁定 1  背景装饰层 -1：在内容栈上下文内置于正文后方，避免不透明背景遮挡文字。
                工作台与弹层不挂背景装饰。
       裁定 2  持久 chrome 收在同一档 15：顶栏与侧栏是同层的两条线，不互相遮盖
                （原侧栏 20 > 顶栏 15）。
       裁定 3  浮层三档：40 = 一次性浮层（账户菜单、搜索面板、通知面板、打卡日历），
                50 = 模态遮罩 + 模态内容，60 = skip-link 与模态之上的系统级提示。
                原 40/45/50 混用（面板比菜单高、遮罩只比面板高 5）已收拢；
                `.global-search__input:focus` 借用的 50 随搜索面板归入 40。
     内容列（.main-content）自身成栈上下文（1），背景装饰挂在它内部，置于正文后方。 */
  --z-content: 1;                              /* 内容列 */
  --z-decor: -1;                               /* 背景装饰：在内容栈内置于正文后方 */

}
