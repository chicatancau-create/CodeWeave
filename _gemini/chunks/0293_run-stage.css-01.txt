/* ============================================================================
   CodeWeave · 运行画布（src/components/run-stage.tsx）
   ----------------------------------------------------------------------------
   这一份给的是 **SVG 画布** 的样式：网格纸底、盒子描边与填充、三态箭头、回边。
   几何在 `engine/stage-layout.ts` 里算（那边是纯函数、可单测），这里只管**看起来**。

   与 flow-chart.css 同一份取值出处：颜色只走 var(--ds-…, 兜底)，间距只走
   --ds-space-*（兜底值与 tokens.css 逐字节相等），圆角只用模板三档。

   四条裁定：

   1) **形状 + 文字 + 颜色三通道，任何一个单独看都还能读。** `kind` 决定轮廓
      （入口/结束是胶囊、处理是圆角方框、判定是六边形、输出是平行四边形），
      `state` 决定描边是虚线还是实线，颜色只做强调。

   2) **网格纸底是这一份的专属。** `background-image` 的两道 linear-gradient 抄的是参考
      实现 `algorithm-visualization-replica/web/style.css` 的 `.canvas-wrap`。页面级样式
      （learning-workspace-view.css）被棘轮禁渐变，**本文件不在那份清单里**——它是组件级
      样式，只服务学习工作台的画布这一处。这不是绕过纪律：那条纪律要禁的是「页面到处
      刷渐变当装饰」，而这里的网格是**画布本体的坐标纸**，是功能性的。

   3) **动效只服务「一步一步显现」，不是装饰。**（2026-10-04 用户要求后改）
      本文件原先写着「不含 @keyframes、不含位移」，那是**当时**的裁定：怕画布刷动效，
      静态截图就读不出状态。用户看过成品后明确要求「一步一步来，加个流畅的动画」——
      需求变了，这条跟着变。现在保留的动效只有一条：`rs-node-enter`，让新走到的那一格
      从画布正中飞回自己的格子。它**不是循环动画**（`animation` 播放一次，无 `infinite`），
      也因此静态截图仍然读得出状态——动画停下来之后每一格都停在它该在的位置上。
      `@media (prefers-reduced-motion)` 与 `.reduce-motion` 两条降级路径照旧全停（见文末）。

   4) **本文件不是基座**：只服务学习工作台这一处，因此不进 subcomponents-base 的
      BASE_FILES，也不写 `.cw-workspace` 前缀——与 flow-chart.css 同为组件级样式。
      级联上与页面样式不冲突：页面规则都带 `.cw-workspace`（多一个类），任何同特异度
      的冲突由页面赢；本文件只声明页面没声明过的属性。

   取值出处（行号 = src/design/tokens.css）：黑场 L27、冷白 L31、次级 L32、
   三级 L33、发丝线 L44/L46、抬起档 L45、场景档 L59、状态色 L73-L76、
   空间阶、圆角、泛光 L104-L107、字栈、缓动、时长。
   ========================================================================== */
