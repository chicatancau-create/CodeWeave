## F. 可复跑的复核方法

**F1 未声明令牌全量检索**（在 `应用端/项目/native/ui-qt/qml/` 下执行）

```python
import re, glob
decl = set(re.findall(r'property\s+[\w<>\[\]]+\s+(\w+)\s*:',
                      open('DesignSystem.qml', encoding='utf-8').read()))
bad = []
for f in glob.glob('**/*.qml', recursive=True):
    for i, l in enumerate(open(f, encoding='utf-8').read().split('\n'), 1):
        if l.strip().startswith('//'):
            continue
        for m in re.finditer(r'\b(?:ds|designSystem)\.(\w+)', l):
            if m.group(1) not in decl:
                bad.append((f, i, m.group(1)))
print('未声明引用:', len(bad))
for b in bad:
    print(' ', b)
```

**F2 写死颜色字面量**（同上目录，排除 `DesignSystem.qml`）

```python
import re, glob
n = 0
for f in sorted(glob.glob('**/*.qml', recursive=True)):
    if f.endswith('DesignSystem.qml'):
        continue
    for i, l in enumerate(open(f, encoding='utf-8').read().split('\n'), 1):
        for m in re.finditer(r'Qt\.rgba\([^)]*\)|"#[0-9a-fA-F]{3,8}"', l):
            print(f, i, m.group(0)); n += 1
print('合计', n)
```

**F3 QML ↔ facade 契约**（在 `应用端/项目/native/ui-qt/` 下执行）

```python
import re, glob
hpp = open('facade/ui_shell.hpp', encoding='utf-8').read()
declared = set(re.findall(r'Q_PROPERTY\s*\(\s*[\w:<>,\s\*&]+?\s+(\w+)\s+READ', hpp))
declared |= set(re.findall(r'Q_INVOKABLE\s+[\w:<>,\s\*&]+?\s+(\w+)\s*\(', hpp))
used = {}
for f in glob.glob('qml/**/*.qml', recursive=True):
    for i, l in enumerate(open(f, encoding='utf-8').read().split('\n'), 1):
        if l.strip().startswith('//'):
            continue
        for m in re.finditer(r'\buiShell\.(\w+)', l):
            used.setdefault(m.group(1), []).append((f, i))
missing = {k: v for k, v in used.items() if k not in declared}
print('未声明的 uiShell 成员:', len(missing))
for k, v in missing.items():
    print(' ', k, v[:2])
```
