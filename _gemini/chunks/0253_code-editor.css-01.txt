/* ============================================================================
   CodeWeave · M4 全站统一 · 代码编辑器基座（src/components/code-editor.tsx）
   ----------------------------------------------------------------------------
   为什么有本文件：M3 做学习工作台时，为了让四区黑场分栏成立，把外观全部限定在
   页面容器作用域内（learning-workspace-view.css 的 169 条规则全部以 `.cw-workspace`
   起头、全局裸选择器 0 条，见 docs/01-应用前端与交互重构方案.md §3），编辑器**自身的
   基座**仍散落在 styles.css 的 `.code-editor` 一族里。编辑器一旦被挑战页 / 项目页 /
   壳外复用，就会露出基座旧形态。本文件把基座本身切到 --ds-* 令牌。

   取值出处（行号 = app/src/design/tokens.css）：
   - 黑场实底 #000 → L25/L26；暖白文字 L27；次级文字 0.56 L28；点缀只用于主操作 L50
   - 发丝线 0.14 / 1px → L37/L40；抬起档 0.16 → L38；输入与焦点边界 → L73-L77
   - 圆角只有三档：0 → L118/L121、50% → L119、100px → L120；零投影 → L123
   - 等宽字栈（含 Windows 中文回退）→ L88；语义状态恒定不插值 → L60-L63
   - 缓动 cubic-bezier(0.22,1,0.36,1) → L147；普通交互 150ms → L153
   规格依据：docs/00-CodeWeave三合一总工程方案.md §5.1（黑场 + 发丝线，移除玻璃卡/渐变/泛光）、
   §5.3 第 1 条（**编辑器默认静态或低动态**）、§5.4（编辑器保留用户字号、长代码行）；
   形态裁定：src/design/geometry.md §2（学习工作台行：禁任何装饰性持续动画）。
   页面侧的同名形态已在 M3 验收：learning-workspace-view.css L345-L468。

   层叠约定（改本文件前必读 —— 这是这里每条选择器都带类型名前缀的唯一原因）：
   1) styles.css 由 main.tsx 引入，实测在产物里排在组件样式**之后**
    （dist/assets/index-*.css：组件样式占 0–95k，styles.css 的 `:root` 起于 94879），
    所以同特异度时 styles.css 赢，只写 `.code-editor` 压不住它。
   2) 本文件只在 (c) 档（类型选择器）上抬一位、(b) 档（类）与 styles.css 保持相等，
    于是：styles.css `.code-editor`(0,1,0) < 本文件 `div.code-editor`(0,1,1)
    < 页面覆写 `.cw-workspace .code-editor`(0,2,0)。页面作用域覆写永远赢，
    **基座改动不会把工作台的观感带偏**（工作台那 39 条用例是这一条的证据）。
   3) 本文件不写任何全局裸选择器，不碰 :root / html / body / *，不新增任何赋值给
    `--editor-font-size` / `--line-height-editor`（§5.4：字号是用户设置，只读取）。
   ========================================================================== */
