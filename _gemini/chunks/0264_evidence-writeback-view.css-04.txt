/* 勾选框：视觉保持 22×22 的自绘方框，命中区用 ::before 外扩到 44×44（§5.4）。
   这一组共用规则同时覆盖本页两颗复选框：待处理列表 .evidence-list 与
   「由我独立完成 / 我已核对确认」两颗 .vault-binding-toggle（见 §8 的说明）。

   为什么必须 appearance:none、而不是给原生框加 ::before——
   原生外观的复选框是**替换元素**，伪元素根本不参与命中。本轮已用**受信点击**实测：
     · appearance:auto + ::before{inset:-11px}：computed style 报 44×44，
       但框外 8px 处 document.elementFromPoint 给的是 MAIN.content-wrap，点下去 checked 不翻；
     · 退而点包裹它的 <label>：命中的又是盖在上面的兄弟节点 P.ewb-state，同样不翻。
   只有 appearance:none 让 input 不再是替换元素，::before 才真正撑出命中区，
   命中点回落到 INPUT 自身（复核脚本 tmp-m6-visual/probe-checkbox-v2.mjs 记有 before/after 两态）。
   写法与 styles.css 的 .setting-row 开关同源：小视觉框 + ::before 外扩命中 + ::after 自绘图形。
   另：§5.4 量的是**目标自身**的命中区，label 包裹只让「点文字」也能勾选，
   验收探针（tools/visual/probes.mjs 的 hitBox）不认它，此前这一档就是 22×22。
   左右 ±11px 落在 label 自身的 10–12px gap / ≥44px 行高内，不越到相邻文字的字形上。 */
.evidence-writeback :is(.evidence-list, .vault-binding-toggle) input[type='checkbox'] {
  appearance: none;
  -webkit-appearance: none;
  position: relative;
  flex: 0 0 auto;
  width: 22px;
  height: 22px;
  margin: 0;
  border: var(--ds-line-width, 1px) solid var(--ewb-edge-active);
  border-radius: var(--ds-radius-control, 0);
  background: var(--ewb-canvas);
  cursor: pointer;
}

/* 命中区：::before 外扩 ±11px（22 → 44），appearance:none 后才是真的可点。 */

  content: '';
  position: absolute;
  inset: -11px;

/* 勾：::after 用右/下两条 2px 边旋转 45° 自绘，只在 :checked 现形，

   pointer-events:none 保证命中区只由 ::before 决定，::after 纯装饰。 */
