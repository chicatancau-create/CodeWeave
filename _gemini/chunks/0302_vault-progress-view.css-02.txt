/* #76 复选框命中区：这一颗只在「资料库已绑定 + 本账户是拥有者」那一档出现，
   所以 §13.4 之前从没被量到过 —— 个人页绑定态第一次进浏览器就量到 hit 18×18。
   原生外观的复选框是**替换元素**，`::before` 不参与命中，加 padding 也不会变命中区；
   写法与 evidence-writeback-view.css 的 #51 同源：appearance:none 自绘，
   ::before 外扩 13px（18 + 13×2 = 44）撑出命中区，勾由 ::after 自绘，
   未勾选是空心描边框 —— 「勾 / 空框」是颜色之外的第二重通道（§5.1 末段）。 */

  appearance: none;
  -webkit-appearance: none;
  position: relative;
  flex: 0 0 auto;
  width: 18px;
  height: 18px;
  margin: 0;
  border: var(--ds-line-width, 1px) solid var(--vp-field-line);
  border-radius: var(--ds-radius-control, 0);
  background: var(--vp-canvas);
  cursor: pointer;
}

  position: absolute;
