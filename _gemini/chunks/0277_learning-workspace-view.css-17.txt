/* ── 代码模式下折掉那条**文字**流程图（2026-10-04 用户要求） ─────────────────
   用户原话：「你现在的画布效果一直就是个文字而已。记得把所有跟代码演示相关的部分，
   全部转换成那个网址（文件夹）中的效果。」

   现在同一份执行轨迹在右栏被画了两遍：
     · `.rs-stage`（SVG 画布）——图形版：节点盒、箭头、回边、指着当前那格的指针；
     · `.flow-chart`（横向文字拍轨）——文字版：一拍一行「01 进入 main / L1 / 场景」。
   画布做完之后，文字那一条说的每件事图上都已有，而且更清楚。用户给的参考站
   （totuma.cn）里也没有第二条文字轨：**画布就是那份可视化**。

   所以代码模式（用户说的「点进跟代码相关的内容」那档）下把文字轨收掉，
   右栏只留画布 + 变量 + 控制台——画布得到的高度正好是文字轨让出来的那两百来像素。

   只在这一档收：普通版式里 `.flow-chart` 照旧在（`lesson.flow` 有数据就画，
   `learning-workspace-view.m3.test.tsx` 钉着 `li.flow-step` 的当前拍与走过拍，
   jsdom 不跑 CSS，那些断言不受影响）。 */
.cw-workspace.is-code-mode .cw-pane--flow .flow-chart {
  display: none;
}

/* ── 画布在场时，那条**文字**流程图不再画（2026-10-04 用户要求「代码转图片」） ──────
   同一份执行轨迹在右栏本来被表达两遍：
     · `.rs-stage`（SVG 画布）——图形：节点盒、箭头、回边、指着当前那格的指针；
     · `.flow-chart`（横向文字拍轨）——文字：一拍一行「01 进入 main / L1 / 场景」。
   用户的原话是「你现在的画布效果一直就是个文字而已」——现在画布是图形的了，
   文字那一条说的每件事图上都有，而且更清楚（参考站 totuma.cn 里也没有第二条文字轨）。

   用 `:has(.rs-stage)` 而不是「一律 display:none」：画布只在**有事件**时渲染
   （`stageFrameAt` 对空 `events` 返回 null）。还没点运行的那一秒，画布是空的，
   这时文字轨就是「这段程序有哪几拍」的唯一交代，留着它有意义；一旦开始运行，
   画布接棒，文字重复项自动让位。规则自己跟着状态走，不需要第二个开关。 */
.cw-workspace .cw-pane--flow:has(.rs-stage) .flow-chart {
  display: none;
}
