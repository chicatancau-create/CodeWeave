备份后台化必须防止“边拷贝边自动保存”造成混合快照；覆盖同一数据根的操作只能串行，不通过暂停 GUI 消息循环实现。窗口关闭进入 Closing 状态，拒绝新任务，发取消但保持事件泵，完成后才回收线程与服务；禁止在仍执行的 worker 上从 UI 直接阻塞 join、detach 或强杀线程。PostMessage/queued signal 只携带可管理生命周期的结果，不捕获已析构 HWND/QObject。

回归包括：取消前/提交中/提交后、进度通知失败、关闭时备份、登录中退出、账户切换与运行竞争、损坏草稿、磁盘写入失败、100 次重复开关任务无线程/句柄增长。修复前后记录消息循环延迟，不通过降低 scrypt 成本、跳过 hash 或放宽锁提高成绩。

### 14.6 给 Flash 的任务拆分

1. U0a：只登记上述调用链和耗时；不改 UI/业务，不按 include 或 IO 命中数推断性能。
2. U0b：任务执行器和取消/关闭契约由有并发审查能力的负责人定稿并提供一个通过测试的样例；Flash 不独立设计线程与锁架构。
3. U0c：Flash 一次只迁移一个已批准的 service 调用，允许文件和回归命令明确；不能同时迁移账户与备份。
4. U1：Qt/编辑器/许可/CRT 选型由负责人验收；Flash 可运行固定 benchmark 与记录结果，不能自行放宽预算。
5. U2：按已冻结 DTO 加薄 facade，QML/页面留给 UI 工作；Flash 后端任务不跨入 UI 目录。

许可证与编辑器结论见总工程：Qt Canvas Painter 和 QScintilla 不作为默认依赖。新增 Qt DLL 或 facade 不意味着可以更改核心数据格式；平台收口逐一迁移，禁止借此重写密码算法或伪造非 Windows 支持。
