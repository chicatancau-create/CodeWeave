## 工作流程规范

### 每次动工前
1. ✅ **必读本工程文件**：确认当前任务和优先级
2. ✅ 读取网页端对应的 CSS 文件：提取关键视觉规格
3. ✅ 读取应用端 Main.qml 对应区域：了解现有实现

### 实施过程中
1. ✅ **90% 复刻网页端**：严格按照 CSS 规格实现
2. ✅ **10% 微调优化**：针对 Qt/QML 平台特性进行合理调整
3. ✅ 使用设计令牌：所有颜色、间距、字体通过 `ds.*` 访问
4. ✅ 平滑动画：使用 `Behavior on property` + 对应 Animation 类型
5. ✅ 交互反馈：为所有可点击元素添加悬停态

### 验证步骤
每完成一个任务后：
1. ✅ 清理 QML 缓存：`rd /S /Q ui-qt\.rcc\qmlcache`
2. ✅ 重新构建：`ninja codeweave-qt` 或运行 `verify3.cmd`
3. ✅ 运行测试：确保 CTest 8/8 全部通过
4. ✅ 手动验证：启动程序，检查视觉效果和交互反馈
