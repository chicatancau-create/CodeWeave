## 运行方式

网页端（`网页端/项目`）：

```powershell
corepack pnpm verify
```

Qt（仓库根）：

```powershell
cmd /c 工程文件\\工具\\构建当前Qt.cmd
node 工程文件\\工具\\check-layout.mjs
```

可见窗口 smoke 需要 Windows 桌面会话、Qt 6.8.3 和当前部署目录；报告目录先创建，再使用 `--qml-load-smoke` 与 `--topbar-reference-content` 参数。存储不可用复测追加 `--qml-load-smoke-preferences-unavailable`。
