# 项目结构索引

## 三端边界

```text
G:/CodeWeave/
├─ 网页端/    # React/TypeScript 网页产品，独立运行
├─ 应用端/    # Windows 桌面产品；当前整理范围
├─ 移动端/    # Android/Kotlin 产品，独立运行
├─ content/   # 应用端 Win32 根入口使用的只读内容包
├─ config/    # 应用端 Win32 根入口使用的配置标记
├─ 工作区/    # 用户工作资料
├─ 备份区/    # 历史归档和回滚材料
├─ 工程文件/  # 项目级索引和基线
└─ app-native-ascii/ # 指向应用端的 ASCII junction，仅供 Qt CMake 构建使用
```

## 入口规则

| 目标 | 唯一入口 | 说明 |
| --- | --- | --- |
| 应用端 Win32 回滚 | `CodeWeave.exe` | 必须与根目录 `content/`、`config/` 同级 |
| 应用端 Qt 预览 | `CodeWeave Qt 预览.lnk` | 指向完整 Qt 部署目录，不使用根目录孤立 EXE |
| 应用端源码 | `应用端/native/` | C++ 核心、Win32 壳和 Qt 壳 |
| 应用端工程文档 | `应用端/工程文件/` | 当前计划、门禁、后端规范和历史说明 |
| 项目历史归档 | `备份区/` | 不参与任何产品运行 |

## 清洁规则

根目录不得新增 Qt 版本副本、重复重建脚本或临时说明。构建产物放在 `G:/CodeWeave-qt/` 或 `应用端/dist/`；本机历史副本放在 `应用端/dist/本机Qt副本-*`；历史文档放在对应端的 `工程文件/历史/`；临时证据放在 `应用端/evidence/`，任务结束后只保留可复核的最终证据。旧 Electron 打包缓存已归档到 `备份区/本机缓存归档-20261009/`，不参与应用端构建。
