Git/AI 必需项 `.git/`、`.gitattributes`、`.gitignore`、`AGENTS.md`、`.claude/` 以及本机英文工具路径 `.local/` 留在根目录并设置隐藏；不迁走 Git 必需文件以免破坏版本控制。“显示隐藏项目”开启时仍可看到它们。

## 固定规则

- 每端最外层只有一个启动链接，其他普通文件全部收入子目录。
- 有用内容合入当前版本；需要的源码与工程资料备份到 Git；确认无用的旧版本、安装包和生成物直接删除，不上传、不另建本地备份堆放区。
- 真实数据、本机配置、凭据、私钥、SDK、依赖不得上传。源代码已有修改必须保留。
- 根目录 `AGENTS.md` 是后续 AI 的固定约束，结构检查：`node 工程文件/工具/check-layout.mjs`。

## 启动与验证

在仓库根目录生成本机快捷方式和内部英文路径：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File 工程文件/工具/初始化本机入口.ps1
node 工程文件/工具/check-layout.mjs
```

网页开发命令在 `网页端/项目` 执行：`corepack pnpm typecheck`、`corepack pnpm lint`、`corepack pnpm test`、`corepack pnpm build`。外层快捷方式运行已构建网页。

在仓库根执行 `工程文件/工具/构建当前Qt.cmd`，通过 `.local/app`、`.local/prep`、`.local/qt` 三个内部英文路径重新配置、编译与测试。路径分别映射应用端项目、Qt 开发环境、构建目录，不是副本。禁止在 G 盘恢复旧 junction。

应用端链接指向 `%LOCALAPPDATA%/Programs/CodeWeave/CodeWeaveQtShell.exe` 的完整已安装版本。清理构建不会删除它；源码构建成功不等于已替换安装版本。不要把孤立 EXE 复制到项目根。

移动端没有 Gradle Wrapper、可用 Gradle 命令、已构建 APK 或检测到的 Android Studio。入口如实提示并打开工程，不自动操作连接的手机。Android 编译和设备运行仍待验证。
