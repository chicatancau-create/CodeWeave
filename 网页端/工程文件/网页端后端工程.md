# 网页端后端工程

## 责任人

由 Codex 负责。后端包括 `server/` 服务、OpenAPI 契约、内容编译、学习进度、证据写回、实例健康和数据权限。

## 第一优先级：代码可视化后端支撑

- 建立不可伪造的执行轨迹模型：输入、步骤、节点、边、变量、输出、错误、时间戳和完成状态。
- 以稳定 ID 和版本号关联课程、挑战、运行实例和轨迹；重复提交必须幂等。
- API 只返回后端实际判定的状态，前端不能自行提升掌握度或完成状态。
- 为暂停、继续、取消、超时、失败和重放定义明确协议；不把动画状态当作业务事实。
- 在视频参考到达后，根据实际交互逐项补充接口，而不是提前锁死视觉实现。

## 其他后端职责

- 维护 OpenAPI 3.1、错误码、输入校验、权限、日志脱敏和 CORS/安全响应头。
- 保持资料库内容、正式学习事实、账户数据和 UI 草稿的边界。
- 为内容读取、学习进度、挑战判题、证据写回提供可回滚的事务语义。
- 先测量再优化：响应时间、查询次数、缓存命中、轨迹大小和并发行为必须有证据。

## 不做的事

- 不实现网页 CSS、视觉布局和动效细节；交给麦当劳模型。
- 不让 Flash 模型决定业务规则、数据库结构或安全策略。
- 不把应用端本地数据、移动端数据或历史备份直接暴露给浏览器。

## 验收命令

`corepack pnpm run contract:check`、服务语法检查、后端测试、独立 `/api/health` smoke、错误路径和并发/幂等测试。未实际执行的命令不能标记为通过。
