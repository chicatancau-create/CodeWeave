函数与方法
把可复用的动作封装起来

【来源】

【运行环境】
教学运行器 · Java 子集

【目标】
把可复用的动作封装起来

【先备知识】
java-loop-sum 单元

【讲解】
Java 的语句按顺序执行；声明变量后才能使用。
把可复用的逻辑封装成函数/方法，输入用参数、结果用返回值。
教学运行器只支持子集语法；真实的编译运行请在本地环境完成（外部环境实验）。

【例子与反例】
正例：先声明再使用：int age = 18; 之后才能读 age
反例：先使用后声明会编译失败
解释：静态类型语言要求先声明类型

【示例代码】
public class Main {
  static int add(int a, int b) { return a + b; }
  public static void main(String[] args) { System.out.println(add(2, 3)); }
}

【理解要点】
在 Java 中，把可复用的动作封装起来。运行并观察每一步的变量变化。

【跟做】
运行示例代码，对照目标输出验证。
按练习要求修改一处数据再运行。
把运行结果与预测对比，不一致就单步排查。

【独立练习】
增加一个乘法函数并调用它。

【变式】
