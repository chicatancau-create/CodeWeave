冒泡排序：从原理到实现
相邻比较 + 交换，推导轮数与复杂度

【来源】
CodeWeave 内置课程快照；学习进度由当前账户证据决定。

【运行环境】
Browser JS 沙箱

【目标】
独立实现冒泡排序，并解释外层为什么是 n-1 轮、复杂度为什么是 O(n²)。

【先备知识】
b1-array-basics

【讲解】
第 1 轮两两比较把最大值送到末尾；第 2 轮只需比较前 n-1 个，依此类推。
外层共 n-1 轮；第 k 轮内层比较 n-k 次 → 总比较约 n²/2，即 O(n²)。
某一轮没有任何交换，说明已经有序，可以提前结束（优化练习）。

【例子与反例】
正例：[5,2,4] 第一轮：5↔2 → [2,5,4]；5↔4 → [2,4,5]，最大值到位
反例：内层写成 j < n，最后一轮访问 arr[n] 越界或做无效比较
解释：内层边界必须随外层递减：j < n - 1 - i

【示例代码】
function bubbleSort(arr) {
  const n = arr.length;
  for (let i = 0; i < n - 1; i++) {
    for (let j = 0; j < n - 1 - i; j++) {
      if (arr[j] > arr[j + 1]) {
        const tmp = arr[j];
        arr[j] = arr[j + 1];
        arr[j + 1] = tmp;
      }
    }
  }
  return arr;
}
console.log(bubbleSort([5, 2, 4, 1]));

【理解要点】
每轮把最大值“冒泡”到末尾：外层 n-1 轮、内层每轮少比一次，这就是 O(n²) 的来源。

【跟做】
运行示例确认输出 [1, 2, 4, 5]。
在交换处加一行 console.log(arr)，观察每轮的冒泡过程。
