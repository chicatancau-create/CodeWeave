数字、文字和列表
认识常见数据类型并访问列表元素

【来源】
CodeWeave 内置课程快照；学习进度由当前账户证据决定。

【运行环境】
Python 3.11

【目标】
认识列表和从 0 开始的索引。

【先备知识】
python-output 单元

【讲解】
列表用方括号包裹、逗号分隔。
scores[0] 是第一个元素；scores[-1] 是最后一个。
越界访问会抛 IndexError。

【例子与反例】
正例：scores[0] 取到 80
反例：scores[3] 越界（长度 3，最大索引 2）
解释：索引范围是 0 到 len-1

【示例代码】
scores = [80, 92, 76]
first = scores[0]
print(first)

【理解要点】
列表把多个值放进一个有顺序的容器，索引从 0 开始。

【跟做】
运行示例确认输出 80。
输出最后一个分数（用 -1 或索引 2）。
追加一个分数并输出整个列表。

【独立练习】
独立创建一个包含 5 个成绩的列表，输出最高分和最低分。

【变式】
输出列表中间位置的元素，要求程序在列表长度变化后仍然正确（提示：len(scores) // 2）。

【项目任务】
通讯录项目用列表保存多个联系人，本单元先完成“读取第一个联系人”。

【常见错误】
索引不能超出范围
第一个元素的索引是 0 而不是 1

【运行方法】
运行按钮（教学运行器支持列表索引子集）

【完成标准】
能解释索引从 0 开始，并安全地访问首尾元素。
