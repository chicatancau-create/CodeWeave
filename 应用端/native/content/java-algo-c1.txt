找出较大值：比较与边界
用分支比较两个数，讨论相等与负数边界

【来源】
CodeWeave 内置课程快照；学习进度由当前账户证据决定。

【运行环境】
教学运行器 · Java 子集

【目标】
独立完成两数取大，并解释相等、负数两组边界的行为。

【先备知识】
B 阶段变量与流程基础

【讲解】
if / else 二选一：条件为真走上面，否则走下面。
a > b 在 a == b 时为假 → 返回 b；max 语义下等价，但要能说出为什么。
竞赛题先想边界（相等、负数、极大值）再写实现。

【例子与反例】
正例：a=4, b=8 → 输出 8
反例：条件写成 a >= b 后说不清相等时返回谁
解释：边界行为必须是推导出来的，不是碰对的

【示例代码】
int a = 4;
int b = 8;
if (a > b) {
    System.out.println(a);
} else {
    System.out.println(b);
}

【理解要点】
比较逻辑是所有选择结构的基础；相等分支是边界思维的第一课。

【跟做】
运行示例确认输出 8。
把 a、b 都改成 5，预测输出并验证。
改成负数 -4 与 -8 再验证。

【独立练习】
独立完成三数取大（两次比较），输出最大值。

【变式】
不改 if 结构，用交换思路把较大值换到 a 中。

【项目任务】
比较逻辑用于通讯录项目中“按名称查找时取更匹配项”。

【常见错误】
边界（相等）分支没有明确答案
整数溢出场景用减法比较（a - b > 0）

【运行方法】
运行按钮（教学运行器支持 int a / int b / if 子集）

【完成标准】
三组数据（一般、相等、负数）输出全部符合预测，并能解释相等分支。

【验收条件】
三组边界数据输出正确
能口头解释相等时返回哪个值
