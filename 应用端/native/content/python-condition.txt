判断一个数字是奇数还是偶数

【来源】
CodeWeave 内置课程快照；学习进度由当前账户证据决定。

【运行环境】
Python 3.11

【目标】
理解条件表达式如何选择不同分支。

【先备知识】
python-loop-sum 单元

【讲解】
% 是取余运算：number % 2 的结果是除以 2 的余数。
余数为 0 说明是偶数；if 的条件是布尔值。
Python 用冒号加缩进表示代码块。

【例子与反例】
正例：8 % 2 == 0 为真 → 输出 偶数
反例：if number % 2 = 0: 用了一个等号，是赋值不是比较
解释：比较用 ==，赋值用 =

【示例代码】
number = 8
if number % 2 == 0:
    result = "偶数"
else:
    result = "奇数"
print(result)

【理解要点】
if 像一个岔路口：条件为真时执行上面的代码，否则执行 else 分支。

【跟做】
运行示例确认输出「偶数」。
把 number 改成 7，先预测再验证。
单步执行观察条件判断的布尔结果。

【独立练习】
独立判断一个数能否被 3 整除，输出「是」或「否」。

【变式】
判断闰年：能被 4 整除但不能被 100 整除（提示：组合两个条件）。

【项目任务】
通讯录项目的菜单分支（1 添加 / 2 查找 / 0 退出）就是 if / else 的应用。

【常见错误】
条件后需要冒号
分支代码需要保持缩进
== 与 = 混用
