## 设计令牌速查表

### 颜色
```qml
ds.page          // 画布背景 #0f131b
ds.ink           // 主文字 #e2e7ef
ds.muted         // 次要文字 #a3afbe
ds.faint         // 三级文字 #8d9bac
ds.line          // 发丝线 #20242b
ds.lineRaised    // 抬升发丝线 #2b313a
ds.accent        // 青色场景色 #8ed5ff

// 语义状态（恒定，不跟随场景）
ds.success       // 成功 #3fd3a4
ds.warning       // 警告 #ffc457
ds.danger        // 危险 #ff8371
ds.info          // 信息 #5b86ff
```

### 间距
```qml
ds.s2, ds.s4, ds.s6, ds.s8, ds.s10, ds.s12
ds.s14, ds.s16, ds.s20, ds.s22, ds.s24, ds.s28, ds.s32
```

### 动画
```qml
ds.durQuick: 150      // 快速过渡
ds.durBase: 220       // 基础过渡
ds.durSlow: 300       // 缓慢过渡
ds.easingType: Easing.OutCubic  // 缓动曲线
```

### 圆角
```qml
ds.radius: 8          // 面板圆角
ds.radiusSm: 5        // 小圆角
// 药丸：100px（仅主操作 CTA）
// 圆形：50%
// 直角：0（默认）
```
