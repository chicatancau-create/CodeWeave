# 挑战提交与人工复核存储契约

日期：2026-11-07。对应 Phase4 P2.4；源码入口为 `项目/native/ui-qt/facade/ui_shell_challenges.cpp` 和 `challenge_submission_store.cpp`。

## 行为边界

- “运行检查”只产生当前关卡运行结果；本地代码全部命中后，填写完成证据并单独提交才创建正式挑战记录。
- 修改代码会使运行结果失效，不能提交旧结果。提交保存代码、目标输出、实际输出、证据、执行等级与判定口径快照；后续改稿不会改变快照。
- 外部环境关卡复用原生外部证据字段校验：执行环境、命令、结果摘要、复现日期必填，日志/截图引用可选；校验长度、有效且不晚于今天的日期和疑似凭据。
- 摘要至少提到一个关卡验收关键词，沿用网页端完整包含或唯一字符覆盖率达到 60% 的宽松诊断。它不验证真实性；不复制网页端诊断列表截断导致多关键词时漏判的实现细节。
- 外部提交状态为 `submitted`，人工复核改为 `verified` 或 `rejected`，不得称为系统自动验证。复核不能重复执行；驳回后可重新提交，旧记录保留。
- 重复点击保存中被合并；与最新未驳回记录相同的证据、代码、输出、目标和执行等级不会重复提交。新待确认记录不会降低已有通过状态；新人工驳回状态可覆盖该关卡的当前状态。
- 本契约不写课程 `EvidenceStore`、`MasteryStore` 或 `ProgressStore`；全局统计与证据写回接入留给 P2.5/P2.7/P2.9，不将挑战通过冒充课程完成。

## 文件和字段

路径相对于已认证账户数据根：`learning/challenge-submissions.v1.json`。本次没有迁移、删除或覆盖旧学习日志；首次保存创建缺失账户目录。真实账户目录不得提交到 Git。

顶层为 `{ "schemaVersion": 1, "records": [...] }`，记录按提交次序追加，查询当前关卡时倒序展示。每个账户最多 1000 条、文件最多 16 MiB；达到上限时拒绝新写入，不自动淘汰历史。

| 字段 | 含义 |
| --- | --- |
| `id` | `submission-` 加 32 位小写十六进制随机标识；同 ID 同内容幂等，冲突拒绝 |
| `challengeId` | 提交时关卡 ID |
| `submittedAt` | UTC ISO 时间，含毫秒 |
| `status` | 本地 `passed`；外部 `submitted` / `verified` / `rejected` |
| `tier` / `judgeMode` | 本地 `teaching` 或 `qt-js` / `exact-lines`；外部 `external` / 空字符串 |
| `evidence` | 提交证据摘要，界面按纯文本呈现 |
| `code` / `expected` / `output` | 代码和逐行输出快照；外部代码及实际输出为空 |
| `observation` | 可选 `completed` / `partially-completed` / `attempted`，不参与判定 |
| `reviewedAt` | 外部已复核记录的 UTC ISO 时间；待确认和自动通过时为空 |

字段编码、ID、状态组合、代码大小（64 KiB）、输出条数（各 100）及输出大小（各 32 KiB）均校验。本地 `passed` 必须通过存储层再次执行的 exact-lines 判定。

## 一致性和恢复

- 串行后台任务负责读写；写入期间阻止切换账户，关闭时排空已提交写任务。账户切换清空内存状态，用账户代次和任务 ID 忽略旧回调。
- 写入使用同路径 `QLockFile` 和 `QSaveFile` 原子替换，禁用直接写入回退；拒绝符号链接及 Windows reparse 路径。
- 损坏、未知版本、无效记录、锁占用和不可写路径均给出状态；不覆盖损坏档案，不把读取失败改为空档案。
- 应用没有删除历史的入口。需要恢复时先关闭应用，保全原档案，由用户检查并从已验证副本恢复；不要通过删档案消除错误。
- 回滚代码不会自动移除本文件。回退到支持本功能之前的版本时，旧版本会保留并忽略该独立文件；不要删除账户目录或运行 Git 清理来回滚学习数据。

仓库根执行 `cmd /c 工程文件\工具\构建当前Qt.cmd`；其中 `qt-facade` 覆盖真实临时目录读写、锁/损坏保护、提交状态、重载、账户隔离及关闭期间的排队写入。窗口矩阵的复现和证据见 `验收证据/Phase4-P2-2-4-submissions-20261107/README.md`。
