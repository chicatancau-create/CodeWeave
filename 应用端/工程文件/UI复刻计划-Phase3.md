## 设计令牌速查表

### 颜色
```qml
ds.page          // 画布背景 #0f131b
ds.ink           // 主文字 #e2e7ef
ds.muted         // 次要文字 #a3afbe
ds.faint         // 三级文字 #8d9bac
ds.line          // 发丝线 #20242b
ds.lineRaised    // 抬升发丝线 #2b313a
ds.accent        // 青色场景色 #8ed5ff

// 语义状态（恒定，不跟随场景）
ds.success       // 成功 #3fd3a4
ds.warning       // 警告 #ffc457
ds.danger        // 危险 #ff8371
ds.info          // 信息 #5b86ff

// 遮光层（纯层次，不表意）
rgba(220, 233, 251, 0.028)   // 一档：分区底色
rgba(220, 233, 251, 0.055)   // 二档：悬停/选中
rgba(220, 233, 251, 0.05)    // 行悬停底色
```

### 发光效果（科技档，装饰性）
```qml
// 近距发光（选中项）
boxShadow: "0 0 0 1px rgba(34, 211, 238, 0.28), 0 0 12px rgba(34, 211, 238, 0.14)"

// 面板发光（卡片悬停）
boxShadow: "0 0 0 1px rgba(120, 175, 235, 0.14), 0 8px 32px rgba(0, 0, 0, 0.55)"

// 内高光（悬停提示）
boxShadow: "inset 0 1px 0 rgba(180, 215, 255, 0.07)"
```

### 间距
```qml
ds.s2, ds.s4, ds.s6, ds.s8, ds.s10, ds.s12
ds.s14, ds.s16, ds.s20, ds.s22, ds.s24, ds.s28, ds.s32
ds.s40, ds.s48

// 响应式间距
clamp(14px, 2.4vw, 30px)     // 水平内边距
clamp(20px, 2.6vw, 32px)     // 垂直内边距
clamp(10px, 1.4vw, 16px)     // 元素间距
```

### 动画
```qml
ds.durQuick: 150      // 快速过渡（颜色、透明度）
ds.durBase: 220       // 基础过渡（悬停、尺寸）
ds.durSlow: 300       // 缓慢过渡（页面切换）
ds.easingType: Easing.OutCubic  // 缓动曲线

// QML 动画实现
Behavior on color {
    ColorAnimation {
        duration: ds.durQuick
        easing.type: ds.easingType
    }
}

Behavior on opacity {
    NumberAnimation {
        duration: ds.durQuick
        easing.type: Easing.Linear
    }
}

Behavior on height {
    NumberAnimation {
        duration: ds.durBase
        easing.type: ds.easingType
    }
}
```

### 圆角
