# A0 原生应用现状与功能基线

修订：2026-10-05。范围仅应用端。原生程序已经接管根目录入口，旧 Electron 源码和启动器只在备份区保留。

## 当前架构

| 区域 | 当前实现 |
| --- | --- |
| 入口及界面 | C++23 / Win32 GUI，无控制台启动器 |
| 业务 | 原生账户、内容、执行、挑战、证据、复习服务 |
| 数据 | 默认 `%LOCALAPPDATA%/CodeWeave`，账户独立目录；支持显式选择数据根 |
| 内容 | 随包 61 条课程、13 条挑战、13 阶段；正文、starter、提示和元数据 |
| 执行 | C++、Java、Python、JavaScript 工具受控运行；外部环境课程记录用户证据 |
| 数据管理 | 用户主动导入旧账户/学习导出；备份与恢复到新目录；不改旧源 |
| 构建 | 应用端原生源码 + 已锁定内容包；不需要网页 dist、Node 后端或 Electron |

内容导出维护工具可以读取旧教学数据生成版本化快照，但编译、打包、运行使用应用端自己的 `native/content`。教学内容来源与网页运行时依赖是两回事。

## 验证方法

核心、账户、进度、导入和备份由 CTest 验证；真实 Win32 smoke 验证课程选择、注册登录、草稿、执行、进度、账户隔离、坏草稿保护和无 TCP/Electron 进程。测试使用隔离数据，不替用户迁移真实资料。

性能历史样本保存在 `../evidence/window-performance-mt.json`；它对应早期候选，不能作为当前最终产品的提速百分比。`--self-test` 只验证启动基本路径。当前交付不作未经同口径实测的性能提升承诺。
