# 课程证据契约

日期：2026-11-07。对应 Phase4 P2.5，不改变现有账本格式，不操作真实用户数据迁移。

## 身份与数据来源

课程正文、验收点、工作台页首和流程图均以 `UiShell.documentId` 为准；`lessonMeta` 没有该文档时，页首使用发布标题，流程节点为空。学习概览选中项不能替代当前打开的文档。

`lessonAssessment` 公开当前文档的契约就绪、运行修订、验收点、完成来源和按钮可用状态。切换文档/账户清除旧契约与运行结果；代码修改后旧运行结果不可用于完成。内容、账户、执行、保存或证据写入忙碌，以及草稿持久化损坏时，完成操作不可用。

## 六种状态

| 状态 | 真实来源 | 是否完成 |
| --- | --- | --- |
| 已阅读 | 学习者显式标记正文已读，Lesson note 使用既有“学习信号：已阅读 · ”前缀 | 否 |
| 已练习 | 本机执行正常退出、无超时/取消/输出失效后记录，note 使用“学习信号：已练习 · ”前缀 | 否 |
| 已提交证据 | 既有外部 EvidenceStore 记录，或含既有结构化字段的 Lesson 记录 | 否 |
| 自评通过 | 学习者显式完成；本地课程无结构化验收点，或外部课程经字段及验收内容校验 | 是，系统未验证外部执行真实性 |
| 自动验证通过 | 当前代码修订本机运行成功，且结构化验收点 exact-lines 全部命中，再由学习者显式完成 | 是 |
| 延迟复测掌握 | 既有 Review 类型的通过事实 | 是，保留复测来源 |

验收沿用既有 `judge_output`：每条预期消耗一个完整输出行，近似/包含不能代替命中；多余输出另列但不否决全部命中。当前内容契约取 `ContentRepository.list_exercises` 的首个练习，与既有课程运行入口一致，没有结构化验收点时不推测目标输出。

外部表单包含环境、命令、结果摘要、可选日志/截图引用和复现日期。字段/长度/疑似凭据/未来日期沿用原生外部证据校验；完成还要求摘要提及当前课程至少一项验收内容。引用仅保存文本，不读取用户指定文件或访问网络。提交待确认与自行声明完成是两个独立操作。

## 存储、并发和兼容性

- 阅读、练习与显式完成追加到当前账户学习数据根下既有 `learning/mastery.v1.log`，使用 Lesson 类型、UUID 事实 ID、operationId 和 UTC 时间，不新增档案版本。
- 阅读/练习 `passed=false`，不会提高掌握等级；显式完成 `passed=true`。非独立完成也保留完成事实，等级和复习排期仍由现有 replay 的独立资格门槛控制，未改动核心门槛。
- 使用 MasteryStore 原有字段校验、锁、追加事务和刷盘；坏账本读失败时拒写。外部提交继续使用 EvidenceStore 的 Pending 状态。
- 单进程忙碌门禁阻止重复写入及写入期间切换账户/文档；记录前读取同课程事实，已标记的阅读/练习/完成不重复追加。未验证两个独立进程同时首次标记的语义去重；UUID 幂等不等同于跨进程的课程语义去重。
- 保存成功后重读六态与复习汇总；账户 ID/代次检查隔离异步结果。失败展示 operationStatus，不覆盖损坏数据。

当前全局分析继续消费原有来源；本项不将阅读信号、完成事实或独立挑战档案重新解释为其他统计。备份导出与正式资料库写回的端到端消费未在本项验收。

## 回滚

本功能只追加兼容事实，无不可逆迁移。工作区干净且确认目标提交后，可 `git revert <P2.5功能提交>` 并运行仓库标准 Qt 构建入口；禁止删除账户账本来回滚。旧版本可解析同格式记录，但不具备本次完成与证据界面。不会自动更新已安装版本或启动链接。
