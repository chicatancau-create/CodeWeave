## 失败、修复和决策

- [先失败，修复后通过] 首次本地提交失败，诊断输出为“挑战提交目录不可写或路径无效”，账户目录存在性为 0。存储不再要求目录预先存在，安全检查后创建账户下 learning 目录；新增首次保存回归，最终 CTest 9/9。
- [先失败，修复后通过] 首轮窗口矩阵新增五张截图后，旧总数断言仍要求 24，实际 29；所有业务检查通过但矩阵失败。数量断言改为精确 29，并保留所有原检查，最终矩阵通过。
- [通过] 人工检查发现复核下拉框使用默认浅色底，已改用现有 ds 令牌；驳回状态补错误色。最终截图和 QML smoke 重新验证。
- 复用原生字段规范，挑战层补验收点提及校验；不将关键词匹配当作外部执行真实性证明。课程证据写入服务的既有测试仍在最终 CTest 中通过。
- 使用独立版本化 JSON 档案保留多条提交，避免把挑战记录混入课程证据、复测排期或课程完成状态。该新档案尚未被旧学习分析/备份导出链消费，后续单独接入。

