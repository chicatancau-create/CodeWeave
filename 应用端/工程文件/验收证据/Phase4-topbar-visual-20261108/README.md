## 几何核对

网页报告包含各 DOM 浮层的 bounding box；Qt 报告当前只记录窗口视口和截图路径，不包含 QML 浮层的独立 bounding box。因此本轮只把以下事实作为几何验收证据：两端均完成 1440×900 的 7 个顶栏场景和 1100×720 的设置场景，截图均在视口内生成；网页端的具体 DOM 尺寸可直接查阅 `web/web-topbar.json`。Qt 面板宽高和内容差异保留在截图中，未把人工估读写成精确数据。

截图人工核对记录：设置外框已对齐 560px 宽及 86% 窗口高度；Qt 行内容与网页的文字、偏好可用性、按钮和选择控件仍有差异。Qt 顶栏搜索靠右且宽度较窄，底层课程为空；网页有 Python 回退课程。帮助正文保留原生执行能力的真实边界，不能直接复制网页能力描述。数据与功能差异不能通过改写截图消除。

## 处理与结论

- 本轮网页端学习指南通过 `QuickActions` 点击时先把焦点还给仍在页面中的快捷动作触发按钮；对应组件测试覆盖打开帮助 Dialog、Esc 关闭及触发按钮归焦。
- Qt 新增 `SettingsContent`、`ShellMenuItem`，调整浮层锚点/尺寸、设置与帮助的标题/分区/按钮；通过设计令牌统一模态背景和留白。未接入的设置保持禁用，不触碰账户数据。
- Qt screenshot smoke 的 DPI 策略仅对验收入口生效，保存前检查 QImage 的实际像素；不缩放图片来制造一致。网页端检查各浮层 bounding box；Qt 当前只检查窗口/图像和窄窗口设置布局，未对所有面板单独做边界断言。
- P1 1.3–1.5 的功能和交互保持已验收；外壳/浮层同状态视觉仍未关闭。下一步需用相同访客/空数据状态生成网页参考，统一课程选择、账户文案和窗口边界后再按面板逐项收敛。
- 截图与报告是正式验收证据，按仓库规则保留；失败前置报告也保留，避免丢失修复轨迹。
