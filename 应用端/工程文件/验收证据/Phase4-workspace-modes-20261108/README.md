# 工作台代码模式、课程指南与帮助验收

日期：2026-11-08。本批补齐工作台模式和课程指南；不是整个 Phase 4 或原始修缮的完成证明。

## 行为

- 有代码或流程元数据的课程默认进入代码模式；隐藏顶栏和侧栏，让编辑器、程序状态和控制台使用工作区宽度。阅读模式恢复外壳、原文和课程完成入口；返回学习页恢复外壳。
- 模式切换不改源码和执行轨迹；同一文档编辑时保留用户选择，新文档重新选择默认模式。
- 课程指南读取当前课程已有 `content`，展示目标、先备、讲解、例子、练习和验收要求；缺失部分显示空态。指南可滚动，Esc 关闭并归焦；页面帮助复用已有帮助弹窗。
- 未执行时默认显示所选课程结构，使用令牌中的节点语义色和虚线；没有执行事件就不伪造执行帧。已有事件继续驱动回看、变量和终态。
- 未修改账户、草稿存储、执行接口、依赖和正式安装版。

## 同尺寸对比结论

| 区块 | 网页端 | Qt | 判断 |
|---|---|---|---|
| 代码模式 | 隐藏外壳，代码与运行画布双栏 | 隐藏外壳，代码与运行画布双栏 | 主结构已补齐；页首控件、工具栏和垂直比例仍不同 |
| 阅读模式 | 外壳、阅读/练习区域 | 外壳、主题原文和完成区域 | 内容来自相同课程；密度和分区位置有差异 |
| 课程指南 | 正文内展开的 region | 可滚动模态 Dialog | 内容同源；交互形式不等价，仍须视觉/产品验收 |
| 未执行程序图 | 四列缩放 SVG，变量区单列独立区域 | 三列固定节点 Canvas，变量在状态面板下部 | 节点语义、未执行状态一致；排列、比例、面板边界不等价 |
| 页面帮助 | 统一学习指南 Dialog | 复用统一帮助 Dialog | 已验证打开、Esc 与归焦；没有宣称像素等价 |

## 复现

在仓库根目录运行标准 Qt 构建。用 `项目/native/ui-qt/deploy-qt.ps1` 将当前 EXE、QML、content 和 config 部署至唯一空 Temp 目录，随后运行：

```powershell
& (Join-Path $stageDeploy 'CodeWeaveQtShell.exe') --visual-comparison-json '<证据目录>/qt/qt-report.json' | Out-Null
& (Join-Path $stageDeploy 'CodeWeaveQtShell.exe') --u3-matrix-json '<证据目录>/matrix/qt-matrix.json' | Out-Null
```

网页参考脚本：`应用端/项目/native/ui-qt/tests/capture_workspace_reference.mjs <外部Playwright目录> <Chrome路径> <本机Vite地址> <证据目录>/web`。不向项目添加 Playwright 依赖。所有输出路径必须指向本机专用证据目录；示例占位符须替换。
