- [通过] 账户菜单 Qt `(1220,57,196×295)`，Web `(1220,56.5,196×296.59)`；快捷动作 Qt `(912,60,268×183)`，Web `(910,59.5,268×183.39)`；通知 Qt `(924,60,300×104)`，Web `(922,59.5,300×103.98)`。浮层主要尺寸相近，快捷动作和通知的水平锚点约差 2px。

- [未执行] 像素差分；正式账户/资料库联调；存储不可用状态下设置标题/说明的 bounds 断言。

## 保留的差异

隔离 Web 参考返回资料库不可用，Qt 使用本机发布目录；通知、设置可用能力和帮助正文也反映各自真实能力。此复测只对照几何与可见性，不将这些不同状态描述为同状态或视觉等价。存储不可用时 Qt 会在已启用偏好的说明后追加状态文案，需要后续增加对应文本边界断言；当前正常偏好状态截图未见裁切。
