## 实现与决策

1. 明细在学习页公共来源条和问候区下加载，保留返回焦点与所选课程；长清单中键盘焦点进入课程会自动滚动至可见位置。
2. 五项统计改为最大 470px 宽纵向细线列表；科目行显示真实单元数、资料库内容和执行能力。
3. 阶段左侧编号与竖线和课程次序/正文/状态三列对齐；课程正文展示说明、元信息、来源、缺口、先备及实际成立的六态证据名称。
4. 当前 native 目录没有 S0–S9 映射，不把 A–M 猜成编号阶段；缺少资料库来源时显示缺口，未引入假进度。
5. Qt `font.family` 原值是 CSS fallback 列表，Qt 将整个字符串当作字体族。Windows UI 改用本机 Microsoft YaHei UI，代码字体用 Consolas；矩阵实际确认标题解析为 Microsoft YaHei UI。没有增加字体依赖，其他平台保留通用字体族。
6. 新矩阵断言覆盖公共页首、纵向统计、科目元信息、证据名称、字体解析、阶段轨道位置、课程正文列对齐和键盘焦点自动滚动。
