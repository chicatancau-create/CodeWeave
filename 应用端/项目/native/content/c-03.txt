条件分支
用 if 和 else 让程序做决定

【来源】
CodeWeave 内置课程快照；学习进度由当前账户证据决定。

【运行环境】
教学运行器 · C 子集

【目标】
用 if 和 else 让程序做决定

【先备知识】
c-loop-sum 单元

【讲解】
C 的语句按顺序执行；声明变量后才能使用。
if / else 根据布尔值选择分支，只会执行其中一条。
教学运行器只支持子集语法；真实的编译运行请在本地环境完成（外部环境实验）。

【例子与反例】
正例：先声明再使用：int age = 18; 之后才能读 age
反例：先使用后声明会编译失败
解释：静态类型语言要求先声明类型

【示例代码】
#include <stdio.h>
int main() { int score = 82; if (score >= 60) printf("通过\n"); else printf("再试一次\n"); return 0; }

【理解要点】
在 C 中，用 if 和 else 让程序做决定。运行并观察每一步的变量变化。

【跟做】
运行示例代码，对照目标输出验证。
按练习要求修改一处数据再运行。
把运行结果与预测对比，不一致就单步排查。

【独立练习】
把 score 改为 59，观察另一条路径。

【变式】
增加第二个条件：score 大于 90 输出「优秀」。
