while 倒数与终止条件
用 while 从 5 倒数到 1，体会终止条件

【来源】
CodeWeave 内置课程快照；学习进度由当前账户证据决定。

【运行环境】
教学运行器 · Java 子集

【目标】
独立完成倒数打印，并解释为什么不会死循环。

【先备知识】
java-algo-c2

【讲解】
while 先判断再执行：count > 0 为假的那一刻循环结束。
循环体必须让 count 逼近终止条件（这里是 -1）。
死循环三要素：条件恒真、变量不更新、更新方向反了。

【例子与反例】
正例：count = count - 1 让条件最终为假
反例：写成 count = count + 1 还期待它停
解释：更新方向决定是否收敛

【示例代码】
int count = 5;
while (count > 0) {
    System.out.println(count);
    count = count - 1;
}

【理解要点】
while 的终止条件写反或漏更新都会死循环；先想清楚“什么时候停”。

【跟做】
运行确认输出 5 4 3 2 1。
把条件改成 count >= 0，预测输出差异（多一个 0）。
故意去掉更新行，观察教学运行器的超时保护。

【独立练习】
独立完成从 n 倒数到 1，n 由变量控制。

【变式】
两个变量：count 从 10 每次 -2，输出全部偶数。

【项目任务】

【常见错误】
条件写 count < 0 一次都不执行
忘记更新 count 导致死循环

【运行方法】
运行按钮（教学运行器支持 while 子集，含超时保护）

【验收条件】
