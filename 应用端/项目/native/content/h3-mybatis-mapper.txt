h1-spring-ioc-di

【讲解】
Mapper 接口与 XML 的 namespace/id 一一对应，参数经 #{} 预编译绑定。
where/if 标签按条件拼句，动态部分同样走预编译。
ORDER BY / 表名无法用 #{} 参数化，必须白名单校验后经 ${} 拼接。

【例子与反例】
正例：LIKE CONCAT("%", #{keyword}, "%") 参数化模糊查询
反例：ORDER BY ${sortColumn} 接收用户输入且未白名单 → 可注入任意 SQL
解释：拼接点必须有白名单

【示例代码】
<select id="search" resultType="Task">
  SELECT * FROM tasks
  <where>
    <if test="keyword != null">AND title LIKE CONCAT("%", #{keyword}, "%")</if>
    <if test="status != null">AND status = #{status}</if>
  </where>
</select>

【理解要点】
#{} 是预编译占位符，${} 是字符串拼接——这个区别就是注入防线。
