让程序说话
使用 print 输出文字和数字

【来源】
CodeWeave 内置课程快照；学习进度由当前账户证据决定。

【运行环境】
Python 3.11

【目标】
掌握文本变量与 print 输出。

【先备知识】
知道如何运行一个 Python 程序

【讲解】
print() 把括号里的内容打印到控制台。
字符串必须用引号包裹，+ 可以拼接两段文本。

【例子与反例】
正例：print("你好，" + name) 输出 你好，小明
反例：print(你好) 没有引号会当成变量名报 NameError
解释：文本是字面量，必须有引号

【示例代码】
name = "小明"
print("你好，" + name)

【理解要点】
输出是观察程序的窗口，先让结果可见，再继续理解内部变化。

【跟做】
运行示例确认输出「你好，小明」。
把名字改成你的名字再运行。
尝试 print(1 + 1) 与 print("1" + "1")，解释差别。

【独立练习】
输出一句话自我介绍，包含名字和年龄两个变量。

【变式】
用三个 print 分别输出三行，再改成用一个 print 输出三行（提示：\n）。

【项目任务】
在命令行通讯录项目里输出格式化的联系人信息。

【常见错误】
字符串必须使用引号
拼接文本与数字时要先转换类型

【运行方法】
运行按钮（教学运行器支持 print 子集）

【完成标准】
能独立输出包含变量的问候语，并解释拼接与加法的区别。
