while 会循环到什么时候？
用条件控制循环结束

【来源】
CodeWeave 内置课程快照；学习进度由当前账户证据决定。

【运行环境】
Python 3.11

【目标】
理解 while 的条件检查和结束时机。

【先备知识】
python-loop-sum 单元

【讲解】
while 先判断条件，为真才执行循环体。
循环体中必须有让条件趋向假的变化。

【例子与反例】
正例：count = count + 1 让条件最终为假
反例：删掉 count = count + 1 会无限循环
解释：条件永远为真时循环无法结束

【示例代码】
count = 1
while count <= 3:
    print(count)
    count = count + 1

【理解要点】
while 每次先检查条件，循环体必须改变条件相关变量，否则可能无限循环。

【跟做】
运行示例确认输出 1、2、3。
改成从 3 倒数到 1。
单步执行观察 count 在条件判断前后的值。

【独立练习】
独立写一个 while 循环计算 1×2×…×5 的乘积。

【变式】
写一个“猜数字”的循环框架：目标值 7，count 从 1 开始每次加 2，输出每次猜测。

【项目任务】
通讯录项目的菜单循环（显示菜单 → 读取选择 → 执行 → 回到菜单）就是 while 的典型应用。

【常见错误】
忘记更新 count
条件方向写反导致一次都不执行

【运行方法】
运行按钮（教学运行器支持 while 子集）

【完成标准】
能预测任意初始值和条件下 while 的输出序列。
