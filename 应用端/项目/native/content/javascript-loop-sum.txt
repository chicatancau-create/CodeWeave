在浏览器里运行 JavaScript
用 let、for 和 console.log 观察变量变化

【来源】
CodeWeave 内置课程快照；学习进度由当前账户证据决定。

【运行环境】
Browser JS 子集

【目标】
理解变量如何在循环中不断更新，并观察最终输出。

【先备知识】
知道什么是变量
会读写一行代码

【讲解】
total 是累加器：每轮循环把当前 i 加进去，循环结束后保存总和。
for 循环由三部分组成：初始化（i = 1）、继续条件（i <= 5）、步进（i += 1）。
range(1, 6)（Python）表示 1 到 5，不包含 6；C/Java 写法是 i <= 5。

【例子与反例】
正例：total = total + i 把当前值累计起来
反例：total = i 只保存了本轮的 i，之前加过的都丢了
解释：累加必须“加上旧值”，否则每轮覆盖

【示例代码】
let total = 0;
for (let i = 1; i <= 5; i++) {
  total += i;
}
console.log(total);

【理解要点】
JavaScript 可以直接在浏览器中运行；修改循环上限，流程和输出会实时改变。

【跟做】
运行示例代码，确认输出 15。
把循环上限改成 10，先在纸上预测结果，再运行验证（应为 55）。
单步执行 3 轮，观察变量面板里 i 和 total 的交替变化。

【独立练习】
独立写出 1 到 100 的累加程序，不运行先说出答案（5050），再用运行结果验证。

【变式】
改成只累加偶数（2 + 4 + … + 100），提示：在循环体里加一个 if 判断。

【项目任务】
把这个累加函数作为命令行通讯录（阶段 B 项目）里“统计联系人数量”的雏形。

【常见错误】
忘记初始化 total
把 < 和 <= 混淆导致少加或多加一次
忘记在循环体中更新 total

【运行方法】
运行按钮（教学运行器支持变量、循环、输出子集）

【完成标准】
能不看示例写出循环累加，并解释任意一轮 total 的值。
