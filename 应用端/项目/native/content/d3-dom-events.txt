DOM 操作与事件：让网页动起来
选择元素、注册事件、更新内容

【来源】
CodeWeave 内置课程快照；学习进度由当前账户证据决定。

【运行环境】
外部环境 · 浏览器 + VSCode

【目标】
独立完成点击计数器，并解释 addEventListener 与 textContent 的作用。

【先备知识】
d1-html-semantics
d2-css-box-model

【讲解】
getElementById 返回单个元素或 null；querySelector 按 CSS 选择器取第一个匹配。
addEventListener(事件名, 处理函数)；移除时必须传入同一个函数引用。
textContent 安全地写文本；innerHTML 插入用户输入会造成 XSS。

【例子与反例】
正例：btn.addEventListener("click", handler) 后 out.textContent = n
反例：<button onclick="alert(1)"> 内联事件，难以维护也无法移除
解释：行为与结构分离才可测试、可复用

【示例代码】
<!-- 在真实页面中验证： -->
<button id="addBtn">+1</button>
<div id="count">0</div>
<script>
  const btn = document.getElementById("addBtn");
  const out = document.getElementById("count");
  let n = 0;
  btn.addEventListener("click", function () {
    n += 1;
    out.textContent = String(n);
  });
</script>

【理解要点】
DOM 编程的固定节奏：选择元素 → 监听事件 → 更新状态 → 写回页面。
