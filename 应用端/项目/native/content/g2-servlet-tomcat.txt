Servlet 与 Tomcat：第一个 Web 容器
请求映射、参数读取与响应写出

【来源】
CodeWeave 内置课程快照；学习进度由当前账户证据决定。

【运行环境】
外部环境 · Tomcat + Maven

【目标】
独立部署一个返回 JSON 的 Servlet 到 Tomcat，并用浏览器/curl 访问成功。

【先备知识】
g1-http-rest-basics

【讲解】
@WebServlet("/tasks") 把路径映射到类；继承 HttpServlet 覆写 doGet/doPost。
HttpServletRequest 读参数与头，HttpServletResponse 写状态、头与体。
War 包放进 webapps 或内嵌 Tomcat 皆可；注意编码统一 UTF-8。

【例子与反例】
正例：先 setContentType 再 getWriter，编码与类型一次到位
反例：直接 getWriter 输出中文且不设编码，浏览器拿到乱码
解释：响应头必须在写体之前设置

【示例代码】
@WebServlet("/tasks")
public class TaskServlet extends HttpServlet {
    @Override
    protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws IOException {
        resp.setContentType("application/json;charset=UTF-8");
        resp.getWriter().write("[{\"id\":1,\"title\":\"demo\"}]");
    }
}

【理解要点】
Servlet 规范定义了“路径 → 处理器”的映射与请求/响应对象；Tomcat 是它的参考实现。

【跟做】
建 Maven Web 项目，写 TaskServlet 并配置 tomcat 插件或外置容器。
curl 访问 /tasks 拿到 JSON。
加 doPost 读取表单参数并回显。

【独立练习】
独立实现 /tasks 的 GET（列表）与 POST（新增，先存内存）。

【变式】
用 Filter 统一给所有响应加 CORS 头。

【项目任务】
这个 Servlet 是 G 阶段验收（Servlet + JDBC + MySQL CRUD）的控制器雏形。

【常见错误】
中文响应不设 UTF-8 出现乱码
在 doGet 里做业务写库却不处理异常

【运行方法】
mvn tomcat7:run 或部署到本地 Tomcat（真实容器）

【完成标准】
两个方法都能被外部请求访问，能解释一次请求在容器内的流转。

【验收条件】
GET 返回合法 JSON
POST 能读取参数并响应
能解释路径映射机制
