第一次写函数
把重复的动作打包成一个工具

【来源】
CodeWeave 内置课程快照；学习进度由当前账户证据决定。

【运行环境】
Python 3.11

【目标】
理解参数、返回值和函数调用。

【先备知识】
python-output 单元
python-loop-sum 单元

【讲解】
def 定义函数；参数是函数的输入。
return 把结果交还给调用方，函数内部不负责打印。
调用 greet("小明") 时，函数体内的 name 就是 "小明"。

【例子与反例】
正例：return message 把结果交出来，调用方决定怎么用
反例：在函数里 print 而 return 空，调用方拿不到值
解释：输出与计算职责要分离，函数才可复用、可测试

【示例代码】
def greet(name):
    message = "你好，" + name
    return message

result = greet("小明")
print(result)

【理解要点】
函数是一个可以重复使用的小盒子：给它输入，它会返回一个结果。

【跟做】
运行示例确认输出「你好，小明」。
给函数增加 age 参数，输出「你好，小明（12 岁）」。
连续调用两次，观察两次结果互不影响。

【独立练习】
独立写 add(a, b) 返回两数之和，并用三个不同输入验证。

【变式】
写 max_of_two(a, b)，用 if 比较 a、b 并返回较大值。

【项目任务】
把“添加联系人”“查找联系人”各写成一个函数，为阶段 B 的命令行 CRUD 做准备。

【常见错误】
函数体需要缩进
return 只返回不负责输出
调用时实参个数与形参不一致
