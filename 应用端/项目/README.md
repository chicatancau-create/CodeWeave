# CodeWeave 应用端当前工程

C++23 核心、Win32 壳与 Qt/QML 壳。外层唯一入口 `../启动应用端.lnk` 指向完整已安装 Qt 应用；源码、构建和已安装版本是不同对象，构建成功不会自动替换安装。

## 目录

- `native/src/`：应用服务、账户、内容、执行、学习记录与 Win32 UI。
- `native/ui-qt/`：Qt facade、QML、部署脚本与测试。
- `native/content/`：唯一原生只读内容源，供打包和测试使用。
- `config/`：不含凭据的版本化配置标记。
- `scripts/`、`tests/`：工具和 Node 测试。
- `../工程文件/`：本端架构、接口与验收说明。
- `../开发环境/`、`../构建产物/qt/current/`：本机工具和唯一当前构建，不上传。
- `workspace/`：已有本机数据，保留且不上传。

## 验证

在本目录执行 `node --test tests/*.test.mjs` 和 `corepack pnpm run check`。

在仓库根执行 `工程文件/工具/构建当前Qt.cmd`，通过内部英文路径重新配置、编译并运行 CTest。不要复用移动前含绝对路径的旧构建缓存。

课程导出工具在构建期读取 `../../网页端/项目/src/data/` 的三个版本化模块；产品运行不启动网页服务，也不读取网页用户数据。学习数据不随本次目录整理迁移。

本地不保留旧交付、旧安装包和重复版本。必要源码备份使用 Git，固定规则见根目录 `AGENTS.md` 和 `../../工程文件/项目结构索引.md`。
