# 移动端总工程

## 项目定位

移动端是 Android/Kotlin UI 与独立 C++ 核心组成的第三个产品方向，与网页端、Windows 应用端同级。当前仍是工程骨架，不能宣称已经完成手机产品。

## 优先级

1. **最高：代码可视化**。先让移动端能消费统一执行轨迹，再根据用户视频复刻实际视觉效果；暂不编写详细操作指南。
2. **第二：模型任务梳理**。Flash 负责结构化、重复性、可验证工作；Codex 负责核心接口、数据和性能；麦当劳模型负责移动 UI 交互。
3. **第三：Android 可运行交付**。补齐 Gradle/SDK/ADB 验证、登录、课程、执行、进度、错误态和同步。

## 四份工程文件

- `移动端总工程.md`：移动端路线、优先级和边界。
- [ 移动端后端工程 ](../移动端后端工程.md)：Codex 负责的 C++ 核心、数据协议和跨端运行支撑。
- [ 移动端Flash模型工程 ](../移动端Flash模型工程.md)：Flash 的重复性任务和证据要求。
- [ 移动端麦当劳模型工程 ](../移动端麦当劳模型工程.md)：UI 交互模型的任务入口名称。

## 当前事实

`mobile-app` 当前只有基础 Activity，`mobile-core` 有独立 C++ 工程；Android APK 和真实设备启动仍需 Android SDK、Gradle Wrapper 与 ADB 验证。

## 未来发展路线

先验证 Android SDK、Gradle 构建及真实设备启动；接通账户、课程、执行与学习记录；再适配统一执行轨迹与触屏交互，最后验证 APK 安装升级。
