# 移动端后端工程

## 责任人

由 Codex 负责。这里包括 C++ 核心、跨端执行轨迹协议、数据同步边界、离线一致性和性能基准，不包括 UI 布局。

## 第一优先级：代码可视化支撑

- 设计平台无关的执行轨迹格式，让 Android UI 能显示节点、边、变量、输出、错误和时间轴。
- 为轨迹版本、取消、暂停、恢复、失败和重放定义稳定接口。
- 保证离线缓存不会伪造正式学习事实；同步采用拥有者范围、版本和幂等键。
- 测量 C++ 核心的执行延迟、内存、序列化成本和大轨迹处理能力。

## 其他职责

- 维护 `mobile-core` 的 CMake、公开头文件、错误模型和测试。
- 设计 JNI/NDK 边界前先冻结数据契约，再由 UI 模型接入。
- 在 Android 环境可用后执行 APK 构建、单元测试、安装启动和最小交互 smoke。

## 禁止事项

不把当前占位 Activity 当成完整产品；不由 Flash 模型决定 C++ API 或数据权限；不在没有视频参考时臆造可视化交互。
